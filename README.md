# Personal Expense Tracker

A simple and interactive web application to manage personal income and expenses, monitor monthly budgets, and visualize financial activities.

## Live Demo

[Open Personal Expense Tracker](https://adithya-26-ds.github.io/Personal-Expense-Tracker/)

## Features

- Add, edit, and delete income and expense transactions.
- View total balance, income, and expenses.
- Search and filter transaction history.
- Visualize expenses using interactive charts.
- Analyze income and expenses over custom date ranges.
- Set monthly budgets and monitor spending.
- Compare monthly income and expenses.
- Identify the highest spending month.
- Export transaction records as CSV.
- Save data using browser Local Storage.

## Technologies Used

- HTML5 – Application structure
- CSS3 – Styling and responsive layout
- JavaScript – Application functionality
- Chart.js – Data visualization
- Local Storage – Browser-based data persistence

## How to Run Locally

1. Clone this repository:

   `git clone https://github.com/adithya-26-ds/Personal-Expense-Tracker.git`

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start tracking your income and expenses.

## Data Storage

The application uses browser Local Storage to save transactions and monthly budget information. Data is stored locally in the browser rather than in a cloud database.
